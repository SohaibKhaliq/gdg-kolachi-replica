# GDG Kolachi homepage — layout replica (unofficial)

Static HTML/CSS/JS layout replica of the GDG Kolachi homepage, built as a
visual-parity study: same section order, dark theme, Google-palette accents
and scroll-driven effects (hero phrase cycle, mission word reveal, flagship
card fan, audience highlight, team brightening, drag gallery).

Not the official site. The official GDG Kolachi site is https://gdgkolachi.com/.
This replica is not affiliated with, endorsed by, or connected to GDG Kolachi
or Google. No photographs, logo artwork, or long copy from the original site
are reproduced here: images are gradient/pattern placeholders at the same
positions, company marks are plain text wordmarks, and team avatars use
initials. Short factual labels (section headings, event titles, team names
and roles, public stats) are used for layout fidelity only.
